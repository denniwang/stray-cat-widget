STRAY CAT FOR MAC

A little company.
A better break.

A stray cat drops by your screen now and then. When it’s time to pause, it helps you look away.

Download for macOS

Free · macOS 13+ · Apple Silicon and Intel

Get Stray Cat

Quick install

Downloads the latest version and opens it.

curl -fsSL https://raw.githubusercontent.com/denniwang/stray-cat-widget/main/install.sh | bash

Homebrew

Install from the Stray Cat tap.

brew tap denniwang/stray-cat-widget https://github.com/denniwang/stray-cat-widget brew install --cask denniwang/stray-cat-widget/straycat
